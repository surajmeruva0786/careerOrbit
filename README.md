# CareerOrbit

An internship sourcing/ranking/tailoring/review pipeline, built for one
user's profile. Automates matching and application prep; a human
approves before anything is submitted, and nothing automates LinkedIn
messaging or logins.

- [`docs/PLAN.md`](docs/PLAN.md) — architecture, data model, build phases
- [`docs/CHANGELOG.md`](docs/CHANGELOG.md) — running build log, newest first
- [`docs/conversation-log.md`](docs/conversation-log.md) — origin and key decisions
- [`app/`](app/README.md) — the Next.js dashboard app; see its README to run it
